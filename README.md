# Monster Energy Collection

Приложение для ведения личной коллекции Monster Energy. Проект создан для хобби и помогает удобно хранить информацию о собранных банках, отслеживать коллекцию и оценивать вкусы.

## Возможности
- Добавление и редактирование банок в коллекции.
- Хранение фотографий и информации о каждом экземпляре.
- Учёт названия, типа, вкуса, стоимости, даты покупки и дизайна банки.
- Оценка вкусов и просмотр рейтинга таблиц (аналог тир-листа).
- Удобный интерфейс с карточками коллекционных банок.

## Технологии
- **C# / .NET 8**
- **WPF / XAML**
- **SQLite**
- **Dapper**

Архитектура проекта постепенно перерабатывается с использованием **MVVM**.

## О проекте
Это мой личный pet-проект, созданный из интереса к коллекционированию Monster Energy и разработке приложений на C#. Проект развивается по мере изучения новых технологий и улучшения структуры кода.
